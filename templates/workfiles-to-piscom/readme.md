# workfiles-to-piscom Template

The workfiles-to-piscom template reads BES alert work files, filters the events, and sends them to iiSCOM over the SCOM connection held by a [piscom-to-tcp](../piscom-to-tcp) pipeline, via an integration-hub pipeline.
